## Image Ad Technical Specifications

### File Requirements

**Format**: JPG or PNG
- JPG for photos/gradients (smaller file size)
- PNG for graphics with transparency or sharp text

**Resolution**: 
- Minimum: Native size (no upscaling)
- DPI: 72 for digital (150+ for print if needed)

**File Size**:
- Maximum: 30MB (platform limit)
- Recommended: Under 1MB for faster loading
- Optimize with TinyPNG or similar

**Color Space**: sRGB (for web/digital)

---

### Typography Standards

**Fonts** (fallback order):
1. Arial (primary - matches brand)
2. Helvetica
3. System sans-serif

**Sizes** (scale by format):
- **1080×1920 (vertical)**:
  - Headline: 72-96pt
  - Subhead: 42-52pt
  - CTA: 36pt
  
- **1200×630 (horizontal)**:
  - Headline: 48-64pt
  - Subhead: 28-36pt
  - CTA: 24pt
  
- **1080×1080 (square)**:
  - Headline: 56-72pt
  - Subhead: 32-42pt
  - CTA: 28pt

**Weight**:
- Headlines: Bold (700)
- Subheads: Regular (400) or Medium (500)
- CTA: Semi-bold (600)

**Line Height**: 1.2-1.3 for headlines, 1.4-1.5 for body

---

### Layout Guidelines

**Safe Zones**:
- Keep critical text/logos 10% from edges
- Account for platform UI overlays (profile pics, buttons)

**Text Contrast**:
- Minimum 4.5:1 ratio (WCAG AA standard)
- Use text shadows or background overlays if needed

**Hierarchy**:
- One primary message (headline)
- One supporting message (subhead)
- One clear CTA
- Logo (subtle, not competing)

**White Space**:
- Don't overcrowd
- Let visuals breathe
- Padding around text blocks

## Platform-Specific Best Practices

### Instagram

- **Feed**: Square (1080×1080) performs best
- **Stories**: Vertical (1080×1920), text in middle-to-upper third
- **Carousel**: Up to 10 images, tell a story across slides
- **Text**: Keep minimal (image-first platform)
- **CTA**: Use platform's CTA button, not just in image

### Facebook

- **Feed**: Horizontal (1200×630) for link previews
- **Text Rule**: Keep text under 20% of image (old rule relaxed but still best practice)
- **Carousel**: 2-10 images, each with unique headline
- **CTA**: Clear, action-oriented

### LinkedIn

- **Format**: Professional, polished
- **Text**: Can be more copy-heavy than Instagram
- **Tone**: ROI-focused, business value
- **Images**: Clean, minimal, data/stats work well

### Twitter/X

- **Format**: 1200×675 horizontal
- **Text**: Concise (image complements tweet text)
- **Engagement**: Ask questions, drive conversation

### Pinterest

- **Format**: Tall (1000×1500) performs best
- **Text**: Overlay works well, readable on small screens
- **Keywords**: Use in pin description for SEO
- **Style**: Infographic-style, educational

### TikTok

- **Format**: 1080×1920 vertical
- **Style**: Less polished OK, authentic
- **Text**: Bold, punchy, mobile-optimized
- **Hook**: First frame must grab attention

## Production Workflow

### 1. Design Phase

- [ ] Create master templates in Figma/Canva/Photoshop
- [ ] Design 1080×1920 vertical first (most versatile)
- [ ] Adapt to horizontal and square formats
- [ ] Export all size variations

### 2. Screenshot Capture

- [ ] Capture UI screens from app (see screenshot-requirements.md)
- [ ] Use light mode (higher contrast for ads)
- [ ] Clean test data (no lorem ipsum)
- [ ] Consistent branding

### 3. Text Overlays

- [ ] Use brand fonts (Arial)
- [ ] Follow hierarchy (headline → subhead → CTA)
- [ ] Check contrast ratios
- [ ] Proofread all copy

### 4. Brand Consistency

- [ ] Logo placement: bottom right or subtle top
- [ ] Color palette: Use brand colors only
- [ ] Warmth Score colors: Accurate to app
- [ ] No stock photos (use real UI or illustrations)

### 5. Export & Optimize

- [ ] Export each platform size
- [ ] Compress images (TinyPNG, ImageOptim)
- [ ] Check file sizes (under 1MB ideal)
- [ ] Name files: `everreach-cpp{1|2}-{platform}-{variant}-{size}.{jpg|png}`

### 6. QA Checklist

- [ ] View on actual mobile device
- [ ] Check text readability
- [ ] Verify CTA is clear
- [ ] Test in platform preview tools
- [ ] Proofread all text (typos kill conversions)

## A/B Testing Matrix

### Test Variables (One at a time)

1. **Headline Copy**: 3 variants per CPP
2. **Visual Style**: Screenshot vs. illustration vs. split-screen
3. **CTA Wording**: "Try Free" vs. "Install Now" vs. "Start Trial"
4. **Color Scheme**: Light background vs. dark vs. gradient
5. **Proof Elements**: With social proof vs. without

### Kill/Scale Criteria

**Kill if** (after 1,000 impressions):
- CTR < 0.8%
- CPC > $3.00 (adjust based on budget)
- Install rate < 1%

**Scale if**:
- CTR > 1.5%
- CPC < $1.50
- Install rate > 2.5%
