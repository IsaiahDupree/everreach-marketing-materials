## Technical Implementation Notes

### UTM Parameters

**CPP 1 (Sales)**:
```
?utm_source={platform}&utm_medium=cpc&utm_campaign=cpp1_sales&utm_content={variant}
```

**CPP 2 (Personal)**:
```
?utm_source={platform}&utm_medium=cpc&utm_campaign=cpp2_personal&utm_content={variant}
```

### Page Load Speed Targets

- First Contentful Paint: <1.8s
- Largest Contentful Paint: <2.5s
- Time to Interactive: <3.8s
- Cumulative Layout Shift: <0.1

### Mobile Optimization

- Responsive design (mobile-first)
- Touch-friendly CTAs (44px minimum height)
- Readable text (16px minimum body)
- Fast load on 3G (test with throttling)

### A/B Testing Setup

**Test Variables** (one at a time):
1. Headline copy (3 variants)
2. CTA wording ("Start Free Trial" vs "Try Free" vs "Get Started")
3. Hero visual (dashboard vs. testimonial vs. results)
4. Social proof placement (above fold vs. mid-page)

**Success Metrics**:
- Conversion rate (email capture or trial start)
- Bounce rate (<40% target)
- Time on page (>90s target)
- Scroll depth (>75% to CTA)

### Trust Elements

- **Security Badges**: SOC 2, GDPR, 256-bit encryption (add once certified)
- **Money-Back Guarantee**: 30 days (if offering)
- **No Credit Card Required**: Emphasize on trial CTAs
- **Privacy Link**: Prominent in footer
- **Contact Info**: support@everreach.app visible

### Forms

**Email Capture Form**:
```html
<form action="/api/signup" method="POST">
  <input type="email" name="email" placeholder="your@email.com" required />
  <input type="hidden" name="utm_source" value="{platform}" />
  <input type="hidden" name="utm_campaign" value="{campaign}" />
  <button type="submit">Start Free Trial</button>
</form>
```

**Validation**:
- Email format check
- Duplicate email handling
- Error messages clear and helpful
- Success redirect to onboarding
